Level solver · Family Sort

A BFS search over board states that answers two questions a puzzle game cannot ship without: is this level solvable at all, and what is the shortest way through it. The generator, the level editor and the validators all sit on top of it, so the same search that proves a level is fair also draws the solution animation a designer watches.

  • Extended for every mechanic added after the first version — hidden colors, lock-and-key chains, frozen and fixed bottles, curtains, ice clusters, carpet groups and tag bottles — each one folded into the same search rather than special-cased beside it.
  • Hidden dependencies (a curtain concealing a colour) are resolved and cleared as the board changes, so the search never reasons from stale state.
  • Cached per level in the gameplay controller, and cloned for the challenge variants, so a mechanic added to the live board reaches the challenge solver too.
  • Handles boards of differing container capacity, which is what let the same solver serve more than one game mode.

Level editors · Family Sort, Cargo Master

In-Unity authoring tools that let designers build and ship levels without an engineer in the loop. The Family Sort editor was used to author 2,000+ shipped levels; the Cargo Master editor I built from scratch as its own scene and app, and it now ships as its own build from the same build script as the game.

  • Visual authoring with brush and palette tools, board resizing, JSON save/load, and one-click playtest straight from the level being edited.
  • Works in any level folder, steps through a set with L-/L+, and loads and saves level variants, so a designer reviews 50 levels without reopening a file dialog.
  • Colour-coded solution playback, so a designer can watch the solver's path rather than read it.
  • Validators that refuse a malformed level at save with a named reason — a frozen bottle without a filled fixed neighbour, an unmapped structure, a colour the board does not contain — instead of failing silently and surfacing as a bug in QA.
  • Design warnings that refresh live as a paint stroke ends, rather than only at save.
  • Bot simulation built into the editor, and a level-check pass that writes its results out as a file for review.

Procedural generation & difficulty · Family Sort

A generator that turns design parameters into solvable puzzles, a bot that plays them so difficulty is measured rather than guessed, and dynamic difficulty that adjusts to the player in production.

  • Weighted distribution over mechanics, so a designer starts from a working level rather than a blank board — including deriving a level's colour set from what is actually used instead of authoring it by hand.
  • Bot-driven difficulty analysis exporting CSV reports, balanced in Google Sheets. This replaced manual playtesting as the primary balancing signal.
  • Dynamic difficulty driven from Remote Config: it eases sooner on easy levels and later on hard ones, and logs the level it judged so every difficulty call can be checked.
  • Level sets integrated in batches, with a drift guard test that catches a set whose files no longer match its looping range.

Gameplay mechanics · Family Sort, Cargo Master, Hop n Sort
